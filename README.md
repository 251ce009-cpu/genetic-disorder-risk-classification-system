# 🧬 Genetic Disorder Risk Classification System

## 1. Project Overview
The Genetic Disorder Risk Classification System is a Machine Learning-based application that predicts the possible genetic disorder category using patient information, genetic history, family history, and clinical details.

This project uses Logistic Regression to classify genetic disorders into different categories.

## 2. Problem Statement
Identifying possible genetic disorder categories from patient information can be challenging. This system uses Machine Learning to support preliminary classification based on the available patient data.

## 3. Objectives
- To analyze genetic disorder datasets.
- To preprocess and clean patient data.
- To develop a Logistic Regression classification model.
- To evaluate model performance using classification metrics.
- To provide predictions through a Streamlit web application.

## 6. Model Evaluation
The model is evaluated using:
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- 5-Fold Cross Validation

### Evaluation Results
- Accuracy: 45.06%
- Precision: 45.64%
- Recall: 55.51%
- F1 Score: 44.93%

## 9. Project Limitation
The model has limited classification performance and may produce incorrect predictions. It is an educational prototype and must not be used for medical diagnosis or treatment decisions.

## 10. Conclusion
The project demonstrates how Machine Learning can be applied to genetic disorder risk classification. It combines data preprocessing, Logistic Regression, model evaluation, Flask API development and Streamlit deployment in one application.
